# Hotel

Sistema web multiempresa para la gestión de hoteles, desarrollado como proyecto académico.

## Objetivo

Desarrollar una aplicación web transaccional que permita gestionar diferentes hoteles, sus habitaciones, reservas, pagos y servicios, utilizando diferentes roles de usuario.

## Funcionalidades principales

- Gestión de hoteles
- Gestión de habitaciones
- Gestión de reservas
- Gestión de pagos
- Gestión de servicios
- Administración de usuarios y roles
- Autenticación de usuarios
- Soporte de internacionalización

## Organización del trabajo

El proyecto utiliza GitHub para el desarrollo colaborativo.

- `main`: rama principal y estable.
- Las nuevas funcionalidades se desarrollan en ramas independientes.
- Cada integrante trabaja utilizando su propia cuenta de GitHub.
- Los cambios se integran mediante Pull Requests.
- Los Pull Requests deben ser revisados por otro integrante antes de incorporarse a `main`.
- Los commits deben ser claros y relacionados con el trabajo realizado.
